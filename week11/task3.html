ProfileCard with Default Prop

avatarUrl is optional, falls back to a default SVG.

function ProfileCard({ name, role, email,
  avatarUrl = DEFAULT_AVATAR }) {
  return <article><img src={avatarUrl} alt={name} />
  <div><h4>{name}</h4><p>{role}</p>
  <a href={`mailto:${email}`}>{email}</a></div></article>;
}

E6

ProductCard Code Challenge

Price, rating, In / Out of Stock.

function ProductCard({ name, price, rating, inStock }) {
  return <article><h4>{name}</h4>
  <p>{price.toLocaleString("ko-KR")}원</p>
  <p>{rating} / 5 stars</p>
  <strong>{inStock ? "In Stock" : "Out of Stock"}</strong>
  </article>;
}

04 / REFLECTION

What I Practiced

  • Functional components return JSX.
  • Props pass data parent → child.
  • Default props make optional inputs safe.
  • .map() + stable keys for lists.
  • Conditional rendering with null, &&, ternary.
  • props.children makes wrappers flexible.

02 — HANDS-ON PRACTICE

From first commit
to friendly 404.

The core steps, collected as quick reference notes.

01GIT BASICS

Start a repository

Initialize Git, add a file to tracking, and make your first snapshot.

$ git init
$ git add index.html
$ git commit -m "Add index page"
02BRANCHES

Build a feature safely

Make a separate branch, commit the change, then merge it back into main.

$ git switch -c feature-style
$ git add style.css && git commit -m "Add styles"
$ git switch main && git merge feature-style
03GITHUB

Share your work

Connect a remote repository and push the branch so it can be reviewed.

$ git remote add origin <repository-url>
$ git push -u origin main
$ gh pr create --base main
04GITHUB PAGES

Publish and handle the edges

Turn on Pages for the main branch, test a missing URL, and add a custom 404 page.

$ git add 404.html
$ git commit -m "Add a helpful 404 page"
$ git push
